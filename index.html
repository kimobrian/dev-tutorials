🚀 Deploy to GitHub Pages

All 15 tutorials live at https://yourusername.github.io/dev-tutorials/ in under 5 minutes. Free, permanent, and automatically updated on every push.

1

Create a public GitHub repository

Go to github.com/new. Name it dev-tutorials. Set to Public. Click Create repository.

2

Set up the folder structure

Extract this zip. Each downloaded tutorial gets renamed to index.html inside its subfolder. The vendor/fuse.min.js file is already included — no CDN needed.

Folder structure
dev-tutorials/
├── index.html              # ← this homepage
├── vendor/
│   └── fuse.min.js         # ← Fuse.js bundled locally (no CDN)
├── aws/index.html          ├── devops/index.html
├── python/index.html       ├── nodejs/index.html
├── ruby/index.html         ├── typescript/index.html
├── react/index.html        ├── react-routing/index.html
├── prisma/index.html       ├── trpc/index.html
├── rust/index.html         ├── dsa/index.html
├── react-routing/index.html    ├── fullstack-rr/index.html
├── system-design/index.html└── databases/index.html
📦 Fuse.js is bundled. Replace the CDN script tag in each tutorial with <script src="../vendor/fuse.min.js"></script> for fully offline search.
3

Push to GitHub

Terminal
git init && git add .
git commit -m "Initial commit"
git remote add origin https://github.com/yourusername/dev-tutorials.git
git branch -M main && git push -u origin main
4

Enable GitHub Pages

Repo → Settings → Pages → Source: Deploy from a branch → main / root → Save. Live in 1–2 minutes at https://yourusername.github.io/dev-tutorials/.

5

Add or update a tutorial

Terminal
git add . && git commit -m "Add React Routing tutorial" && git push

GitHub Pages rebuilds in under 60 seconds. No server, no CI config.
